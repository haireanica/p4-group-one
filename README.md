# Orlando Lend IT – Android Application

## Requirements

- Java 21 JDK
- MySQL Server
- MySQL Workbench (recommended)
- Android Studio
- Android SDK
- Windows, macOS, or Linux

## How to Run

### Step 1: Set Up and Run the Backend

1. Switch to the **Beta-WebApp-With-Backend** branch of the project repository.
2. Follow the instructions in the web app branch README to set up the database and configure and run the Spring Boot backend.
3. Leave the backend running while using the Android application.

### Step 2: Run the Android Application

1. Open the Android project in Android Studio.
2. Allow Android Studio to sync Gradle and resolve any required dependencies.
3. Open **Device Manager** and select an available Android emulator, or connect a physical Android device.
4. Verify that the application is configured to connect to the running backend server.
5. Select the Android application run configuration and click **Run (▶)** to build and launch the application in the emulator or connected device.

### Step 3: Log In

- **Username:** `admin`
- **Password:** `AdminPassword`
