# Orlando Lend IT – iOS Application

## Requirements

- Java 21 JDK
- MySQL Server
- MySQL Workbench (recommended)
- Xcode
- macOS

## How to Run

### Step 1: Set Up and Run the Backend

1. Switch to the **Beta-WebApp-With-Backend** of the project repository.
2. Follow the instructions in the web app branch README to set up the database and configure and run the Spring Boot backend.
3. Leave the backend running while using the iOS application.

### Step 2: Run the iOS Application

1. Open the iOS project in Xcode.
2. Allow Xcode to resolve any required dependencies.
3. Select an available iPhone simulator from the device selection menu.
4. Verify that the application is configured to connect to the running backend server.
5. Select the application scheme and click **Run (▶)** to build and launch the application in the simulator.

### Step 3: Log In

- **Username:** `admin`
- **Password:** `AdminPassword`
